# Sign up for Akamai Functions

Sign up for the Akamai Functions free trial to get up and running quickly.

To access Functions, you currently need an Akamai Control Center account. If you don't have one yet, you can use the [steps below](https://techdocs.akamai.com/akamai-functions/docs/sign-up-for-akamai-functions#create-an-akamai-functions-trial-account) to sign up. If you already have an account, you can [Activate Akamai Functions in MarketPlace](https://techdocs.akamai.com/akamai-functions/docs/sign-up-for-akamai-functions#activate-akamai-functions-in-marketplace).

If you're unable to sign up for an Akamai Control Center account, contact your Akamai account team for information about other options. In the future, Akamai Functions will also support access via [Cloud Manager](https://techdocs.akamai.com/cloud-computing/docs/cloud-manager).

# Create an Akamai Functions trial account

Follow these steps to sign up for an Akamai Control Center (ACC) account. You can use your ACC login to sign up for access to a trial version of Akamai Functions in Marketplace. If you’re already an Akamai customer and have an ACC account you can skip this step and go to [Activate Akamai Functions in Marketplace](https://techdocs.akamai.com/akamai-functions/docs/sign-up-for-akamai-functions#activate-akamai-functions-in-marketplace).

1. Navigate to the [Book a demo section](https://www.akamai.com/products/akamai-functions#demo) on the Akamai Functions homepage.

2. Fill in the form and click **Submit**.

3. When your demo request is approved by Akamai, you’ll receive an email asking you to reset your password and activate your account.

4. Next, review and accept the terms and conditions to get started. Then click on **Start Free Trial**.

   It might take a few moments for Akamai to finish provisioning.

5. When onboarding is complete, you can activate Akamai Functions from Akamai's Marketplace.

# Activate Akamai Functions in Marketplace

Follow these instructions to activate Akamai Functions in Akamai's Marketplace. To enable Functions via Marketplace, you need an active ​Akamai​ contract and login credentials for ​Akamai Control Center​ to sign up for the 30-day free trial. If you need help signing up or would like more information, contact an ​Akamai​ account representative.

1. Login to Akamai Control Center.

> 👍
>
> If you don't have an Akamai account and login credentials follow the steps in [Create a trial account]() to create one.

2. Navigate to Marketplace by clicking on the shopping cart icon:

   ![Shopping cart icon](https://techdocs.akamai.com/edgeworkers/img/shopping-cart-icon-v1.png)

3. Once you navigate to Marketplace, search for Akamai Functions.

4. Click the **Learn More** button to select select Akamai Functions.

5. On the Trial Details page, click Try to begin your trial.

6. Review the terms and conditions. If you agree, select the “I accept the Terms and Conditions” checkbox, then click **Start Trial**.

Now you’re ready to start using Akamai Functions to create your very first application.

> 📘
>
> For more information review the [Quickstart](https://techdocs.akamai.com/akamai-functions/docs/quickstart) section in this guide. These instructions include an end-to-end example. You can also review the [Manage accounts](https://techdocs.akamai.com/akamai-functions/docs/manage-accounts) topic for details about the Akamai Functions account types.

## Start using Akamai Functions

Once you've activated the Akamai Functions free trial, you can login and follow the steps in the [Quickstart](https://techdocs.akamai.com/akamai-functions/docs/quickstart) guide to get started.

Once you login you'll have access to your personal account and at least one team account. A team account is available for each contract where Akamai Functions is enabled. For more information, see [Manage  accounts](https://techdocs.akamai.com/akamai-functions/docs/manage-accounts).
