# FAQ

### Where are Akamai Functions available today?

Akamai Functions are currently deployed throughout the world in more than 25 regions.

### How are Spin applications managed within a Akamai Functions account?

The Akamai Functions account system uses Akamai Control Center as an identity provider. For more information, see [Sign up for Akamai Functions](https://techdocs.akamai.com/akamai-functions/docs/sign-up-for-akamai-functions).

There are two Akamai Functions account types, personal and team. You can use your personal account for experimentation and testing. Team accounts are for collaboration and production deployments and include access to the full limit and request counts specified in your contract.

Upon first login, your personal account is automatically created and you are automatically added to the default team account for your contract. For more information on how to use different accounts go to [Manage accounts](https://techdocs.akamai.com/akamai-functions/docs/manage-accounts) in this guide.

### How long does a login session last with Akamai Functions? Will my Spin applications persist after I’ve been logged out?

Your login session started by `spin aka login` persists for 15 days without activity. To learn more about the `spin aka` plugin, please visit the [Spin aka command reference](https://techdocs.akamai.com/akamai-functions/docs/aka-command-reference).

### How do I get help with Akamai Functions?

We’re here to help! Please contact your Akamai representative if you need help.
