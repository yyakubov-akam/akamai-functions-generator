# WebAssembly standards

Here's a curated list of pages that tracks WebAssembly standards.

# WebAssembly Standard and W3 Working Group

WebAssembly is standardized by W3C, the same group that standardizes CSS, HTML, and HTTP.

* [W3’s official Wasm site](https://www.w3.org/groups/wg/wasm/).
* Almost all of the working drafts of proposed standards are in the [WebAssembly GitHub Org](https://github.com/WebAssembly).
  * All proposals are in one [repo](https://github.com/WebAssembly/proposals).
  * Refer to the [meetings repo](https://github.com/WebAssembly/meetings) for the events schedule.
* [W3 GitHub repo](https://github.com/w3c/wasm-wg/).
* [W3 Community Page](https://www.w3.org/community/webassembly/).

# WebAssembly System Interface (WASI)

* [WASI](https://wasi.dev/) .
* [WASI repo](https://github.com/WebAssembly/WASI).
* The working group [charter](https://github.com/WebAssembly/WASI/blob/main/docs/Charter.md).
* Most of the WASI proposed standards are in the [WebAssembly GitHub](https://github.com/orgs/WebAssembly/repositories?q=wasi).
* The [WASI libc library](https://github.com/WebAssembly/wasi-libc) is the C library for core WASI.

# The Component Model

One very important WebAssembly specification is the Component Model.

* [Proposal](https://github.com/WebAssembly/component-model).
* [Design and specification](https://github.com/WebAssembly/component-model).
* A great [intro blog post](https://www.fermyon.com/blog/webassembly-component-model?_gl=1*co5ar1*_ga*NzAxNjk3OTI0LjE3NzI3MTc5OTU.*_ga_DXM7W0VBXS*czE3NzMyMzYwOTQkbzMkZzEkdDE3NzMyNzAyMDAkajMzJGwwJGgw).

# WebAssembly Gateway Interface (Wagi)

DeisLabs (at Microsoft) proposed Wagi based on the CGI 1.1 specification.

* The architecture document is in the [Wagi server repo](https://github.com/deislabs/wagi/blob/main/docs/architecture.md).
* [Environment variables](https://github.com/deislabs/wagi/blob/main/docs/environment_variables.md) description.
* Spin’s [Wagi support](https://spinframework.dev/v2/http-trigger).
