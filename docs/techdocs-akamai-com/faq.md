## Supported APIs and Syntax

`spin aka login` — initiates a login session for the current user. The session remains active for 30 days of inactivity.  

`spin aka` — entry point for the Akamai Functions CLI plugin; provides additional account‑management commands (refer to the *aka command reference* for full details).
