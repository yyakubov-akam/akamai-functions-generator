## Supported APIs and Syntax
- `spin aka` — Spin plugin that provides Akamai Functions commands.  
- `spin aka deploy` — Deploys a Spin application to Akamai Functions with a single command.

## Version and Compatibility Notes
- Akamai Functions is currently in **public preview** with limited availability; APIs and behavior may change before general release.  
- Only the **Spin SDKs** for Rust, Go, JavaScript, and Python are supported, and applications must be compiled to **WebAssembly** to run on the Akamai Functions runtime.
