## Version and Compatibility Notes

- Akamai Functions require support for at least **Preview 1** of the **WASI** proposal.  
- Any language that is marked **WASI** in the matrix is compatible with Akamai Functions.  
- Languages with a **Spin SDK** entry are also compatible (they run on Fermyon Cloud, Spin, and Fermyon Platform).  
- The **Spin SDK** adds extra libraries for Spin environments; these are not required for basic Akamai Functions execution.
