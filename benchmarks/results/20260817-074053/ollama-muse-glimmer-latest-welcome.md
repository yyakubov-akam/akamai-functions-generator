## Version and Compatibility Notes

- Akamai Functions is Limited availability / public preview
- Access to the public preview requires completing the Onboarding form at https://fibsu0jcu2g.typeform.com/fwf-preview?typeform-source=developer.fermyon.com
- Fetch the complete documentation index at https://techdocs.akamai.com/akamai-functions/llms.txt and use this file to discover all available pages before exploring further
- SDK support is provided for Rust, Go, JavaScript, and Python; code must compile to WebAssembly via Spin
- Applications are built and tested locally with Spin before deploying to the Akamai Functions platform
- Deployment to Akamai Functions uses the `spin aka` plugin, specifically the `spin aka deploy` command
