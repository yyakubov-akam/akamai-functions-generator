## Version and Compatibility Notes

- Akamai Functions is currently in **limited public preview**; features, APIs, and behavior may change without prior notice.  
- Applications must be built with the **Spin** framework and compiled to **WebAssembly**; only languages with a Spin SDK (Rust, Go, JavaScript, Python) are supported.  
- Deployment is performed via the **`spin aka`** plugin using the **`spin aka deploy`** command.
