## Runtime Constraints

- Use the Spin framework for building and running applications.
- Applications must be compiled to WebAssembly (Wasm).
- Development must follow the Spin-based execution model.

## Supported APIs and Syntax

- `spin aka deploy` — Command used to deploy Spin applications to the Akaks Akamai Functions platform.

## Version and Compatibility Notes

- Akamai Functions is currently in limited availability (public preview).
- The runtime is based on the Spin framework and WebAssembly.
- SDK support is available for Rust, Go, JavaScript, and Python.
